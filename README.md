# PearlMart Inventory Management System

> CMPS310 Software Engineering – Fall 2026 | Group 4 – Milestone 1

 brief about the project: an automated inventory management system for PearlMart, a medium-sized retail store, replacing manual record keeping. It supports warehouse and billing-counter activities (stock in/out, expiry tracking, supplier orders, sales, replacements, customer requests, and reports) 
 as one consistent system.
 Milestone 1 covers requirements analysis (DFDs, use cases), object-oriented design (class diagram), and Scrum-based project management.

## Workflow

1. Create or pick a GitHub Issue (with acceptance criteria, one assignee, and type/priority/phase labels).
2. Create a branch linked to the issue.
3. Open a Pull Request linked to the issue.
4. A teammate reviews the PR.
5. Merge into `main` after approval.
